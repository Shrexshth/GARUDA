# GAURDA

A sovereign, on-premise, agentic AI workbench for Mangalore Refinery and Petrochemicals Limited (MRPL) - SIH 26117 submission.

This system is designed as a scalable architecture currently configured to run entirely on a single MacBook Air M4 with 16GB of unified memory.

## Running the Application
Please refer to `docs/SETUP.md` for initial setup.
To run the application, execute:
```bash
./run.sh
```
